# Identité visuelle MobSanté

Le composant global `BrandMark` utilise seulement
`mobsante_pictogram_transparent.png`. Le composant `ActionThemeMark` peut
superposer `mobilization_flame.png` lorsque le thème de l'Action est `fire`.
Le modèle `Operation` ne dépend d'aucun asset.

Le pictogramme applicatif réunit uniquement :

- la croix de santé ;
- la figure humaine ;
- les deux courbes rouge et bleue.

`mobsante_pictogram_master.png` est la source haute définition neutre des
icônes web et PWA. `mobsante_app_icon_master.png` conserve l'ancienne variante
avec flamme pour référence historique et ne représente plus la plateforme.
Les anciens
fichiers `logo_hd.png` et `logo_ui_256.png` restent des sources
institutionnelles distinctes et ne sont pas utilisés directement comme icône
applicative.
